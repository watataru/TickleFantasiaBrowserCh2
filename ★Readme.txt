ティクルファンタジア(ver0.200)
作者：わたたる
作者ブログ：https://ci-en.dlsite.com/creator/23059
ツイッター：@watatarutaru

このゲームはRPGツクールMZによって制作されたくすぐりRPGです。
性的な描写を含むため、18歳未満の方はプレイをご遠慮ください。


■起動方法
Game.exeをダブルクリックしてください。

■セーブデータの引継ぎ方法
引継ぎ元フォルダ内の「save」フォルダをフォルダごと引継ぎ先フォルダにコピーペーストしてください。

■操作方法
移動、選択　　　		　　：方向キー
決定　　　			　　：Zキー
キャンセル、メニュー画面を開く	　　：Xキー
ダッシュ（オプションで変更可能）　：Shiftキー
メッセージの早送り、戦闘の高速化　：Sキー
メッセージウィンドウ消去	　　：Ctrlキー、右クリック
メッセージログの表示（戦闘中以外）：Tabキー
タイトル画面に戻る		　　：F5キー


■セーブについて
本作にオートセーブ機能はありません。
メニュー画面の「セーブ」にてこまめにセーブを行ってください。
ほとんどのボス戦では、負けるとゲームオーバーになってしまいます。


■オプションについて
メニュー画面で開けるオプションでは、以下項目を設定できます。
・バトル難易度：「カジュアル」にすると敵が弱体化し、ゲームを進めやすくなります。
　　　　　　　　バトル難易度はメニュー画面が開ける場面であればいつでも変更可能であり、
		くすぐりシーンやシーン回想には一切影響しません。

・バトル中くすぐり：「見ない」にするとバトル中のくすぐりシーンをスキップすることができます。

■シーン回想について
・タイトル画面からシーン回想に移動することができます。
　ゲームプレイ中の場合、タイトル画面の「ゲーム終了」やF5キーでタイトル画面に戻って下さい。

・シーン回想はゲームを進めることで解放されていきます。
　実際にそのシーンを閲覧している必要はありません。章をクリアする頃にはその章の全てのシーンが解放されています。
　また、シーン回想にてゲームの進行状況にかかわらず全てのシーンを解放することも可能です。


■ゲーム中の機能について
・戦闘中にくすぐってくる敵は、ターゲット選択時に白い手のアイコンが付いています。
　また、マップ上では白いシンボルになっています。

・戦闘中に「特技」の「前に出る」を使用することで、くすぐり攻撃に狙われやすくすることができます。
　ターンスキップ行為として使用することもできます。

・各地のショップにいる闇商人（フードの人）から「自爆爆弾」を購入することで、
　即座に全滅することができます。
